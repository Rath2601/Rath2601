## Systems & Architectural Focus

- **Event-driven architecture** — Kafka-based messaging with tuned consumer concurrency, strict partition ordering, and event reprocessing for reliable delivery across distributed services.
- **Transactional reliability** — data consistency across multi-region distributed SQL (PostgreSQL, CockroachDB), with query-level tuning to bound latency and round-trips.
- **Secure API boundaries** — OAuth-signed service-to-service exchange, attribute-based (ABAC) authorization, and tokenization to keep sensitive data out of downstream flows.
- **Containerized delivery** — Docker + ArgoCD GitOps pipelines with CI/CD and automated testing ahead of release.
